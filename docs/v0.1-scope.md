# Version 0.1 scope

## Included

- Native CLI binaries for macOS and Windows.
- Local TOML configuration and SQLite storage.
- Native credential-store integration.
- JSON import plus JSON and CSV export.
- OpenAI and Anthropic provider adapters.
- Usage and cost reports for common and custom time ranges.
- Provider, model, and project grouping.
- Local budget definition and checks.
- Diagnostics, database backup, data deletion, and shell completion.

## Excluded

- macOS menu bar or notch interface.
- Windows tray interface.
- Background daemon, scheduled collection, or notifications.
- Cloud sync, hosted accounts, or team administration.
- Prompt or response collection.
- Scraping consumer subscription dashboards.
- Executable third-party plugins.
- Linux release support guarantees.

These exclusions keep v0.1 focused on a dependable cross-platform data core.
Excluded features may be designed later, but they must not be partially hidden
inside the initial CLI.

## Release gate

Version 0.1 is complete only when installation, setup, import, both provider
adapters, reporting, budgets, diagnostics, export, backup, and deletion are
documented and pass the macOS and Windows test matrix.
