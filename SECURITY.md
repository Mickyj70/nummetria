# Security policy

## Supported versions

Nummetria has not published a stable release. Security fixes currently target
the default branch and the newest prerelease when one exists. A formal support
window will be published with v0.1.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability, credential leak, or
privacy failure. Use GitHub's private vulnerability reporting flow for this
repository instead.

Include, when possible:

- The affected version, commit, and operating system.
- A clear description of the impact.
- Minimal reproduction steps using fake credentials and sanitized data.
- Any suggested mitigation.

You should receive an acknowledgement within seven days. We will investigate,
coordinate a fix and disclosure when appropriate, and credit reporters who want
to be credited.

## Sensitive data

Never attach real API keys, access tokens, provider payloads, prompts, responses,
database files, or credential-store screenshots to a report. Replace sensitive
values with obvious placeholders.
